# FastAPI Project

یہ ایک FastAPI پراجیکٹ ہے جسے Git اور GitHub کے ساتھ مربوط (integrate) کیا گیا ہے۔

## شروع کرنے کا طریقہ (Getting Started)

1. ورچوئل انوائرنمنٹ (Virtual Environment) بنائیں:
   ```bash
   python -m venv venv
   ```

2. انوائرنمنٹ ایکٹیویٹ کریں:
   ```bash
   .\venv\Scripts\activate
   ```

3. ڈیپینڈینسیز انسٹال کریں:
   ```bash
   pip install -r requirements.txt
   ```

4. سرور چلائیں:
   ```bash
   uvicorn main:app --reload
   ```
